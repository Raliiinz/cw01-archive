
# Контрольная работа № 1 — Система архивирования

Система архивирования файлов на базе Yandex Cloud.

## Технологии

- Python 3.12
- Yandex Cloud Functions
- Yandex API Gateway
- Yandex Message Queue
- Yandex Managed Service for YDB
- Yandex Object Storage
- Terraform
- OpenAPI 3.0

## Описание

Система принимает задания на архивирование файлов по URL,
асинхронно скачивает файлы, создаёт ZIP-архивы и сохраняет
метаданные в базе данных.

API позволяет создавать задания, получать список архивов,
просматривать информацию об архиве и скачивать ZIP-файлы.

## Развёртывание

Инфраструктура управляется Terraform.

Входные переменные:
- cloud_id
- folder_id
- bucket_name

Аутентификация выполняется через переменную окружения YC_TOKEN.

Подробная инструкция по развёртыванию будет добавлена
после реализации системы.
